**OSF README**
================

## Introduction

This the README file for the project *LaDeNetST: Language Development Networks and Screen Time* which was created to document the paper entitled **"Dense Connectivity in Networks of Red-Flag Language Milestones Among High Screen-Time Children"**. The manuscript was prepared for submission and subsequently submitted to [*Frontiers in Psychology*](https://www.frontiersin.org/journals/psychology) journal in November 2025.


## Purpose

The materials archived here are intended to ensure full transparency and reproducibility of the analyses reported in the manuscript. Although the [GitHub repository](https://osf.io/7jyd6/files/412bf7f0-5425-45bf-8ee6-b0b7cad2759b?view_only=3d246e5cd90749b9bdf6db1bf69e33f7) linked to this OSF project is synchronized, occasional inconsistencies have been observed. To mitigate potential access issues—particularly during the peer review process—a [compressed version of the entire project folder has been uploaded as a ZIP file](https://osf.io/7jyd6/files/osfstorage/68b34d26bb455b40f7e67970?view_only=3d246e5cd90749b9bdf6db1bf69e33f7) available in the [OSF storage section](https://osf.io/7jyd6/files/osfstorage?view_only=3d246e5cd90749b9bdf6db1bf69e33f7).

## Contents
The [ZIP archive](https://osf.io/7jyd6/files/osfstorage/68b34d26bb455b40f7e67970?view_only=3d246e5cd90749b9bdf6db1bf69e33f7) includes:

- README files (descriptive metadata for each component of the project).
  - The README is provided in both HTML and PDF formats. In OSF [.MD README](https://osf.io/xhg74?view_only=3d246e5cd90749b9bdf6db1bf69e33f7) and [PDF README](https://osf.io/yzn3c?view_only=3d246e5cd90749b9bdf6db1bf69e33f7) can be visualized.
  - The HTML version is particularly recommended, as it was designed to function as a hyperlinked project within GitHub. It enables intuitive navigation across files and embedded links, facilitating a more interactive and structured exploration of the project components.
  - The PDF version offers a static alternative for offline viewing or archival purposes.
- Source code (R scripts and functions used for data processing and analysis).
- Data files.
- Tables, figures, and intermediate datasets.

## Access for Reviewers

A [blind link](https://osf.io/7jyd6/?view_only=3d246e5cd90749b9bdf6db1bf69e33f7) has been generated to facilitate anonymous access for reviewers. All relevant files are accessible directly through this [OSF repository](https://osf.io/7jyd6/files/osfstorage?view_only=3d246e5cd90749b9bdf6db1bf69e33f7), ensuring that no dependencies on external platforms (e.g., GitHub) compromise the review process.
